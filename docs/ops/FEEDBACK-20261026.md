## 用户约定

- 默认进入全部 / AI 精选，再次从根入口打开恢复当前账号的上次范围、筛选与排序；明确文章深链保留。
- 支持日、自然周（周一至周日）、自然月；沿用账号阅读时区。原有原生严格下界与 AI 包含下界的秒级契约不在这次改动中扩大。
- 可支持站点先取完整正文、持久保存核验回执，再做预翻译。完成翻译不等于原文完整性已经核验。
- 原文获取失败与模型输出失败分开处理。核验瞬时失败最多初次加两次重试，状态跨服务重启保留；403、404、410、未接入站点明确说明限制。
- 普通开源发布 / release notes 源已由用户删除，禁止通过 catalog 导入、订阅刷新或历史 manifest 恢复。
- GitHub issue、PR、合并、部署、验收与交接由执行者闭环。不得只交付待合并 PR。

## 本轮确认的问题

| 证据 | 结论与处理 |
|---|---|
| HomeRedirect 的 all → today 改写及 resetInboxLandingView | 移除强制跳转；用已有账号身份键保存最近范围、AI 筛选和日期/搜索，根入口恢复。新默认为全部 |
| 12615 两份 HTML 的正文文字与翻译块完全相同 | 对已核验原文允许严格匹配完整翻译块及行内语义后复用，保留当前标记和图片；正文、普通链接、用户、模型或提示词变化仍隔离 |
| 12604、12599 补取后有更多段落 | 这是先翻 RSS、打开详情后才补正文的时机问题，不能都称为出版方更新；自动预翻译提前走同一核验路径 |
| 补取正文图片为源站 URL，绕过原生 Miniflux 的图片代理改写 | 对响应展示副本补签同一代理，canonical HTML、核验哈希、译文缓存均保留；同时在清理 HTML 前恢复源站明确的 lazy 图片地址 |
| 深页所有已载入封面排在 FIFO 尾部，下载未结束无槽位超时 | 可见深页优先使用下一空槽，15 秒释放挂起预取；仍为 6 路、同一 1 GiB 缓存；封面失败提供最多 3 次手动重试 |
| 当前源目录之外仍有 298 条 done 分析，历史统计未过滤 | 当前订阅计数按实时目录过滤，分母优先使用原生条目总数；已读和未读均包括，因此与侧栏未读数并非同一口径；历史记录保留 |
| 模型失败已有 25 条 attempts=3；部分抓取失败也已达三次 | 不清零重算。统一模型初次加两次重试及停止文案；基础设施失败沿用独立计数 |

上述数量为本轮诊断快照，后续任务继续运行会变化，不能当成固定当前值。

## 删源与 Kaggle

回收逐条核实原生条目。明确 404/410 标为已移除；不可达、认证失败或超时仍属于未知，不能当成已删除。已移除结果不写分析、不重试模型；混合卡片批次只导入仍存在且当前输入匹配的部分。已有历史结果、预算与失败回执不清空。
