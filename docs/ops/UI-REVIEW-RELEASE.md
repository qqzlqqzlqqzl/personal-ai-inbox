## 用户可见变化

1. 翻译提示不再成为横向卡片的第二列。它只在卡片内部显示简短状态；翻译关闭时不显示“等待”，已有中文缓存保留，顶部一次说明暂停状态。
2. AI 精选的时间/评分升降序真正传到后端。时间比较按实际时刻而非 ISO 字符串；下拉提供最新/最旧，评分按钮显示高分/低分，避免语义冲突。
3. 保留详情大标题的原站链接，正文及附件下方增加“打开原始网页 ↗”。两者使用同一有效原始 URL，在新标签打开。
4. 云下载操作明确叫“重新抓取正文”；自动保存选项仍默认关闭，行为没有改成自动开启。

## 主动审查发现并修复

- #11：抓取失败/空响应被当成功后按钮禁用；旧文章的请求也可能误改新文章按钮。现在按文章 ID 维护状态，成功才完成，失败可重试；旧结果不替换新正文。
- #12：AI 全局隐藏只看订阅，忽略分类隐藏。现与原生可见范围一致。
- #13：按入库时间分页错误地用时间桶选择 ID 游标。批量导入源真实复现 81 篇只到 21 篇；改用实际消费的 ID 边界，升降序都有逻辑回归。
- 列表模式在正文延迟加载时可能没有简介：保留已缓存的中文简介或 AI 摘要。
- 标题更新后旧中文缓存不能继续冒充已完成翻译。
